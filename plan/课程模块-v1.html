Fit101 的课程页面

为什么 · 1 个请求 将目前我已经上的三节课和未来要上的9节课，教练给我规划的内容进行可视化，由于目前的一些专业名词我不是特别熟悉。我经常会忘记某个词对应的动作是什么样子的 我希望可以在网页上显示我每一次课程的各组动作的中英文，一个动态图展示这个动作是做什么的。我使用的器械名称和对应的重量。以及一两句话介绍这个动作的要点是什么 关于svg生成，你可以考虑参考训记这个app中的风格……对于每一个动作，我们可以点开一个expandable的卡片看到它锻炼的肌肉是哪一块 长远来看，我甚至希望可以制作一个属于我自己的健身app。但是现在为了简单，让我们只实现网页版本。但是请考虑电脑和手机端的适配

每一节课的页面把每个动作显示为一张卡片：中英文名、动图、器械和重量、要点。

英文名是教练表格里的原名。 起始和结束两帧交替，每秒切换一次。 单位用 lb，旁边写 kg。 我写要点，你可以改。

动图从哪里来？
覆盖 教练教过的 20 个动作里，TRX 划船、Pallof press、弹力带横走在这个库里可能没有。缺的动作用最接近的动作代替，并在卡片上注明。
做法 不逐个手画。用一套关节骨架加姿势关键帧生成 SVG，24 个动作共用一个人体，动作只定义起止姿势和器械。

重量用什么单位显示？

生成脚本把每个动作写成一个 ### 标题加一段 HTML 卡片。

html-author 用 ### 做目录，所以每个动作都能从目录跳到。 marked 原样输出 HTML，不用改 html-author。

两帧动画只用 CSS 完成，不需要 JavaScript。

卡片在深色模式下也正确。 两帧交替，看起来像慢速 GIF。 见第 4 条。

每张卡片可以展开，显示这个动作练到的肌肉：主要肌群深色，辅助肌群浅色。

主要和辅助分开写，脚本给 SVG 区域加 class。

左侧目录列出 12 节课。已上的课有内容，未上的课显示为“待上课”。

页面存在，内容是占位。

页面怎么分？

一节课在 sessions.json 里有 status，生成脚本按它决定页面内容。

还没上的 9 节课，页面上先放什么？

“动作库”页面把每个动作只列一次，并写出它出现在哪几节课。

动作库不用手填，脚本从 12 节课汇总。

在手机上，目录栏变成顶部抽屉，卡片变成上下排列。

点开能跳到任一动作或任一节课。

上完一节课，只改一个数据文件，跑一条命令，网站就更新。

上完课之后，怎么把内容记进来？
后果 没有数据文件，以后做 app 时要重新整理数据。

项目只有一个新文件夹，生成的文件和手写的文件分开放。

生成脚本先写 Markdown，再调用 html-author，自己不写 HTML 页面。

done 出卡片，planned 出占位。 样式和目录栏都来自它。fit.css 由每页顶部的 link 引入。

共用：两个 JSON 文件的形状。

不动的部分：Resources 里的两个表格、健身档案、html-author 本身。
